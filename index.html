01고지기간 계산기

청약 예정일 입력

청약일을 기준으로 각 고지기간의 시작일을 계산합니다. 표준사업방법서 <부표1> 기준 ‘최근 ○개월 이내’ = 청약일의 ○개월 전일부터 청약일까지입니다(2024.12.20 신설).

청약 예정일을 입력하면 3개월·1년·2년·3년·5년·10년 구간의 시작일이 여기에 표시됩니다. 이 화면(미리보기)에서는 계산기가 실행되지 않으니 Safari에서 열기로 열어 주세요.
청약일 기준 고지기간 구간 안내가 여기에 표시됩니다.

일반심사(표준) 체크리스트

  • 심사 유형(일반심사 · 간편심사 3·5·5 등)을 고르면 그 유형의 문항과 실무 포인트가 여기에 표시됩니다. 미리보기에서는 아래 ‘유형별 한눈 비교’ 표로 구조를 먼저 확인하세요.
계산 기준 3가지
① ‘계속하여 7일 이상 치료 / 30일 이상 투약’은 같은 원인으로 치료 시작 후 완료일까지 실제 받은 일수입니다(중간 공백은 제외).
② 보험료 납입연체로 해지된 계약을 부활(효력회복)하는 경우, 1~5번 문항의 기간은 ‘해지일 이후 ~ 부활 청약일’과 원래 기간 중 짧은 쪽입니다(2023.6.26 신설).
③ 고지 시점은 청약일이고, 위반 여부 판단은 계약 성립 시 기준입니다. 청약 당일 받은 진단도 고지 대상이 될 수 있습니다(대법원 2010다78135).

유형별 한눈 비교

가운데 숫자만 입원·수술을 묻는 기간이 달라집니다. 3개월·5년 문항은 대체로 공통입니다.

02질환·진료 검색

질환명·진료명·증상으로 검색하거나 카테고리로 좁혀 보세요. 카드를 누르면 고지 포인트·필요 서류·심사 유의점이 열립니다.

⌕
질환·진료 카드 목록은 Safari에서 열기로 열어 검색어를 입력하면 표시됩니다.
공통 원칙. 아래 내용은 표준약관·표준사업방법서와 금감원 분쟁조정 사례를 실무 관점으로 정리한 것입니다. 보험사별 인수기준(부담보·할증·거절)은 다르므로, ‘고지 대상인지’와 ‘인수가 되는지’를 나눠서 확인하십시오.
03보험사별 인수기준

기준일과 확인 범위

보험사 인수기준은 월 단위로도 바뀝니다. 이 화면은 공시·상품안내·보도로 공개된 내용만 담았고, 각 항목마다 확인 시점과 출처 성격을 붙였습니다.

기준일·확인 범위 안내가 여기에 표시됩니다.
반드시 재확인. 각 사 내부 언더라이팅 매뉴얼·전산 심사기준은 대외비이고 수시로 개정됩니다. 여기 적힌 예외질환 수·부담보 기간·할인율은 공개된 시점의 값입니다. 견적·청약 전에 토스인슈어런스 사내 전산과 각 사 담당 매니저 공지로 그 주의 최신 기준을 확인하십시오.

보험사별 공개 인수기준

명함상 취급 보험사는 33곳(손해 14·생명 19)이고, 그중 공개 자료로 간편심사 기준이 확인된 손해보험 14곳·생명보험 17곳(총 31곳)의 2026년 라인업과 인수 특징입니다. 상단에서 손해보험·생명보험을 골라 볼 수 있습니다.

보험사별 공개 인수기준 카드가 여기에 표시됩니다. 미리보기에서는 목록이 실행되지 않으니 Safari에서 열기로 확인해 주세요.
읽는 법. ‘예외질환 개수’는 그 질환이 있어도 조건 없이 인수되는 질병 코드 수입니다. 코드 분류가 회사마다 달라서 개수만으로 우열을 비교할 수 없습니다. 같은 회사 안에서도 상품·고지유형별로 예외 범위가 다릅니다.

경증질환·단기 진료 — 공개된 예외 사례

‘이 정도는 넘어가겠지’라고 생각하는 항목이 실제로는 고지 대상인 경우가 많습니다. 공개된 예외·완화 사례만 모았습니다.

단기 통원·단순 감기·비염·위염
3개월 문항의 ‘투약’은 처방 행위 자체라서 청약서에는 ‘예’로 적는 것이 원칙입니다. 인수 단계의 예외는 별개 — 한화생명은 위염 등 600개 경미질환을 조건 없이 즉시 인수, 신한라이프는 장염을 대기 3개월→1개월로 단축.
2026.2~8 공개 보도 기준
대장용종·자궁근종 (수술 직후)
미래에셋생명은 두 질환을 수술 직후에도 간편심사 예외질환으로 포함. 다른 사는 대개 경과기간을 둡니다.
2026.8 기준
백내장
미래에셋생명 예외질환 보류기간 3년 → 1년. 한화생명은 경미질환 다발력자 특별인수 사례로 백내장 수술 고객을 제시.
2026.10~11 기준
유방양성종양·디스크·척추협착
신한라이프는 보장기간 전체가 아닌 일정 기간만 부담보. 한화생명은 척추질환 등 1,600개를 3개월 경과·입원 4일 이하 조건 없이 인수.
2026.2~8 기준
치질·담석·자궁내막증·하지정맥류
DB손해보험은 365간편플랜에 즉시인수 예외질환 215개를 두고 대장용종·위용종·치질·담석증·자궁내막증·자궁근종·하지정맥류를 완치 시 즉시 인수 대상으로 안내합니다. 라이나생명은 담관염·요관결석·백내장을 치료 종결 시 즉시 인수.
2025.5~2026.9 공개 보도 기준
제왕절개
공개된 사별 예외 기준이 확인되지 않았습니다. 청약서에 수술(제왕절개 포함)로 명시되어 있어 고지 대상인 것은 분명하고, 수술 후 경과기간별 인수 조건은 사별 내규입니다. 사별 심사팀 문의로만 확인 가능.
2026.11 확인 · 공개 자료 없음
핵심 구분. ①청약서에 고지하는 것 ②회사가 인수하는 것은 다른 단계입니다. 예외질환이라도 문항에 해당하면 ‘예’로 적어야 하고, 그 다음에 부담보·할증 없이 받아주는지를 봅니다.

질환별로 보기

질환을 고르면 공개된 보험사별 심사 포인트만 모아 보여줍니다.

자료 업데이트 방법

본부 공지나 각 사 인수기준표(PDF·텍스트)를 받으면, 이 문서(index.html) 맨 위의 ‘데이터 영역’ 스크립트 블록만 고치면 됩니다. 화면 코드는 건드리지 않아도 됩니다.

① 보험사 카드 — INSURERS 배열에 한 칸씩 추가
{ name:'회사명', type:'손해보험'|'생명보험', asOf:'2026.11', srcType:'공시|보도', lineups:[...], points:[...], watch:[...], src:'출처' }
② 질환별 포인트 — DISEASE_INS에 질환명 키로 추가
'질환명': [ { ins:'회사명', txt:'내용', asOf:'2026.11' } ]
③ 질환·진료 검색기 — 같은 블록의 DATA 배열
{ cat:'카테고리', name:'이름', tag:['3개월'], kw:'검색어', sm:'한 줄 요약', pts:[...], docs:[...], tip:'현장 팁' }
기준일 바꾸기 — META.asOf 값만 바꾸면 상단 기준일 표시가 함께 바뀝니다.
